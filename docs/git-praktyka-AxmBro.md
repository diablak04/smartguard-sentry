## Czego nauczyłem się?
Nauczyłem się pracować z Gitem z poziomu terminala, od sklonowania repozytorium do Pull Requesta. Na osobnej gałęzi mogę wprowadzać zmiany bez ryzyka, że zepsuję `main`. Wiem, że `git add` wybiera zmiany do commita, `git commit` zapisuje je lokalnie, a `git push` wysyła je na GitHuba. `git status` pomaga sprawdzić przed commitem, na jakiej gałęzi jestem i co dokładnie zostanie zapisane.

## Różnica między Git i GitHub
Git to program do wersjonowania, działa lokalnie na moim komputerze. GitHub to serwis w internecie, gdzie trzymamy repozytorium i robimy Pull Requesty.
